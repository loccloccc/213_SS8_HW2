# Quy trình Xử lý Sự cố CRM
Khi nhận được yêu cầu từ khách hàng, nhân viên CSKH cần thực hiện các bước sau:
1. Tiếp nhận và ghi nhận thông tin.
2. Phân loại sự cố.
3. Hỗ trợ khách hàng.
4. Đóng ticket.

## Chi tiết Hỗ trợ khách hàng
- Cung cấp thông tin tài khoản.
- Reset mật khẩu.
- Hỗ trợ đổi trả hàng.
